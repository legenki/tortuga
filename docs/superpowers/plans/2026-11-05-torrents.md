# Torrents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Download files from torrent links: a click on a `magnet:` or `.torrent` link (or the context menu, or a paste in the popup) opens a confirm window with the torrent's name and size, and the popup's Downloads tab shows progress with pause, resume and remove (keeping or deleting files).

**Architecture:** The helper gets a `torrents` module on `librqbit` 9.1.0, opened lazily on the first torrent request, with JSON persistence so downloads resume. The extension talks to it over a **second native port** (its own helper process), so downloads work whether Tor is on or off and the two processes never share state. In the extension, `Downloads` (background) owns that port; a content script catches torrent links; `confirm.html` shows what a torrent is before anything downloads. Torrents connect directly, never through Tor.

**Tech Stack:** Rust (`librqbit` / `librqbit-core` =9.1.0, `base64` 0.22), TypeScript / Vite / Vitest as before, Python 3 for the helper's end-to-end script, headless Firefox over WebDriver BiDi for the live check.

Spec: `docs/superpowers/specs/2026-11-05-tortuga-design.md` (*Helper → Torrents*, *Starting a download*, *Popup*).

## Global Constraints

- Torrents never go through Tor; every place a download starts says "from your own IP, not through Tor".
- Nothing downloads before the user presses **Download** in the confirm window.
- A torrent's id in the protocol is its info hash (hex), stable across restarts.
- Only `magnet:` links with `xt=urn:btih|btmh` and http(s) links whose path ends in `.torrent` are taken (`isTorrentLink`), in pages and in the background.
- `.torrent` URLs are fetched by the helper itself, without the browser's cookies (private trackers that need a login are not supported in v1).
- Files go to `~/Downloads/Tortuga` (`TORTUGA_DOWNLOADS` overrides it for tests); the torrent list lives in the helper's data dir (`TORTUGA_DATA_DIR/torrents` in tests).
- Tests never write to `~/Downloads`; unit tests never touch the network (offline librqbit session).
- The protocol stays version 1 (only new message types).

//! Torrent downloads with librqbit. They connect directly, not through Tor
//! (the Tor Project asks people not to run BitTorrent over Tor). A torrent is
//! known to the extension by its info hash, which survives restarts.

use std::path::PathBuf;
use std::str::FromStr;
use std::sync::Arc;

use librqbit::api::TorrentIdOrHash;
use librqbit::{AddTorrent, AddTorrentOptions, AddTorrentResponse, ManagedTorrent, Session, SessionOptions, SessionPersistenceConfig, TorrentStatsState};
use librqbit_core::hash_id::Id20;
use serde::Serialize;

/// What the extension sends to name a torrent: a magnet link or an http(s)
/// URL of a `.torrent` file (fetched by librqbit), or the file's bytes.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Source {
    Url(String),
    File(Vec<u8>),
}

/// Name, size and file count, for the confirm window.
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct TorrentInfo {
    pub id: String,
    pub name: String,
    pub size: u64,
    pub files: usize,
    pub folder: String,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "lowercase")]
pub enum TorrentState {
    Starting,
    Downloading,
    Seeding,
    Paused,
    Error,
}

/// One row of the Downloads tab.
#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct Progress {
    pub id: String,
    pub name: String,
    pub done: u64,
    pub size: u64,
    /// Bytes per second.
    pub down_rate: u64,
    pub up_rate: u64,
    pub state: TorrentState,
    pub error: Option<String>,
}

/// A librqbit speed in MiB/s as bytes per second.
fn bytes_per_second(mibps: f64) -> u64 {
    (mibps * 1024.0 * 1024.0).round().max(0.0) as u64
}

/// The row state from librqbit's state and whether all bytes are there.
pub fn state_for(stats: &TorrentStatsState, finished: bool, error: bool) -> TorrentState {
    if error {
        return TorrentState::Error;
    }
    match stats {
        TorrentStatsState::Initializing { .. } => TorrentState::Starting,
        TorrentStatsState::Paused => TorrentState::Paused,
        TorrentStatsState::Error => TorrentState::Error,
        TorrentStatsState::Live if finished => TorrentState::Seeding,
        TorrentStatsState::Live => TorrentState::Downloading,
    }
}

fn parse_id(id: &str) -> anyhow::Result<TorrentIdOrHash> {
    Ok(TorrentIdOrHash::Hash(Id20::from_str(id).map_err(|e| anyhow::anyhow!("bad torrent id {id}: {e}"))?))
}

fn add_request(source: &Source) -> AddTorrent<'static> {
    match source {
        Source::Url(url) => AddTorrent::from_url(url.clone()),
        Source::File(bytes) => AddTorrent::from_bytes(bytes.clone()),
    }
}

pub struct Torrents {
    session: Arc<Session>,
    folder: PathBuf,
}

impl Torrents {
    /// Open the session: files go to `folder`, the list of torrents is kept in
    /// `state_dir` and resumed on the next start.
    pub async fn open(folder: PathBuf, state_dir: PathBuf) -> anyhow::Result<Self> {
        Self::open_with(folder, state_dir, SessionOptions::default()).await
    }

    async fn open_with(folder: PathBuf, state_dir: PathBuf, opts: SessionOptions) -> anyhow::Result<Self> {
        std::fs::create_dir_all(&folder)?;
        std::fs::create_dir_all(&state_dir)?;
        let opts = SessionOptions {
            persistence: Some(SessionPersistenceConfig::Json { folder: Some(state_dir) }),
            fastresume: true,
            ..opts
        };
        let session = Session::new_with_opts(folder.clone(), opts).await?;
        Ok(Self { session, folder })
    }

    /// Fetch the torrent's metadata (from peers, for a magnet) without downloading.
    pub async fn inspect(&self, source: &Source) -> anyhow::Result<TorrentInfo> {
        let opts = AddTorrentOptions { list_only: true, ..Default::default() };
        match self.session.add_torrent(add_request(source), Some(opts)).await? {
            AddTorrentResponse::ListOnly(r) => Ok(TorrentInfo {
                id: r.info_hash.as_string(),
                name: r.info.name().map(|n| n.into_owned()).unwrap_or_else(|| r.info_hash.as_string()),
                size: r.info.iter_file_lengths().sum(),
                files: r.info.iter_file_lengths().count(),
                folder: self.folder.display().to_string(),
            }),
            AddTorrentResponse::AlreadyManaged(_, handle) | AddTorrentResponse::Added(_, handle) => Ok(self.info_of(&handle)),
        }
    }

    /// Start downloading; adding one that is already there just returns it.
    pub async fn add(&self, source: &Source) -> anyhow::Result<TorrentInfo> {
        match self.session.add_torrent(add_request(source), None).await? {
            AddTorrentResponse::Added(_, handle) | AddTorrentResponse::AlreadyManaged(_, handle) => Ok(self.info_of(&handle)),
            AddTorrentResponse::ListOnly(_) => anyhow::bail!("librqbit answered list-only to a download"),
        }
    }

    pub async fn pause(&self, id: &str) -> anyhow::Result<()> {
        let handle = self.handle(id)?;
        self.session.pause(&handle).await
    }

    pub async fn resume(&self, id: &str) -> anyhow::Result<()> {
        let handle = self.handle(id)?;
        self.session.unpause(&handle).await
    }

    /// Stop it (and its seeding); with `delete_files` its files go too.
    pub async fn remove(&self, id: &str, delete_files: bool) -> anyhow::Result<()> {
        self.session.delete(parse_id(id)?, delete_files).await
    }

    /// A row for every torrent, in the order they were added.
    pub fn progress(&self) -> Vec<Progress> {
        self.session.with_torrents(|torrents| {
            torrents
                .map(|(_, t)| {
                    let stats = t.stats();
                    let (down_rate, up_rate) = stats
                        .live
                        .as_ref()
                        .map(|l| (bytes_per_second(l.download_speed.mbps), bytes_per_second(l.upload_speed.mbps)))
                        .unwrap_or((0, 0));
                    Progress {
                        id: t.info_hash().as_string(),
                        name: t.name().unwrap_or_else(|| t.info_hash().as_string()),
                        done: stats.progress_bytes,
                        size: stats.total_bytes,
                        down_rate,
                        up_rate,
                        state: state_for(&stats.state, stats.finished, stats.error.is_some()),
                        error: stats.error.clone(),
                    }
                })
                .collect()
        })
    }

    fn handle(&self, id: &str) -> anyhow::Result<Arc<ManagedTorrent>> {
        self.session.get(parse_id(id)?).ok_or_else(|| anyhow::anyhow!("no torrent {id}"))
    }

    /// Size and file count come from the metadata: the stats are empty while
    /// a torrent is still starting.
    fn info_of(&self, handle: &ManagedTorrent) -> TorrentInfo {
        let (size, files) = handle
            .with_metadata(|m| (m.info.iter_file_lengths().sum(), m.info.iter_file_lengths().count()))
            .unwrap_or((handle.stats().total_bytes, 0));
        TorrentInfo {
            id: handle.info_hash().as_string(),
            name: handle.name().unwrap_or_else(|| handle.info_hash().as_string()),
            size,
            files,
            folder: self.folder.display().to_string(),
        }
    }
}

//! Where the helper keeps its files, and the Arti config for a bridge choice.

use std::path::PathBuf;

use arti_client::config::pt::TransportConfigBuilder;
use arti_client::config::{BridgeConfigBuilder, CfgPath, TorClientConfig, TorClientConfigBuilder};

use crate::protocol::{BridgeChoice, BridgeKind};

/// The helper's own directories and the bundled transport.
#[derive(Debug, Clone)]
pub struct Paths {
    pub state_dir: PathBuf,
    pub cache_dir: PathBuf,
    /// `lyrebird`, serving obfs4, WebTunnel, meek and Snowflake.
    pub lyrebird: PathBuf,
    /// The Expert Bundle's `pt_config.json`, for the default Snowflake bridges.
    pub pt_config: PathBuf,
    /// Where torrents are saved: `TORTUGA_DOWNLOADS`, else `~/Downloads/Tortuga`.
    pub downloads: PathBuf,
    /// The torrent list, resumed on the next start.
    pub torrent_state: PathBuf,
}

impl Paths {
    /// Data under `TORTUGA_DATA_DIR` if set (tests, cold-start runs), else the
    /// platform's data and cache dirs. Transports under `TORTUGA_PT_DIR` if
    /// set, else `pt/` next to the executable.
    pub fn discover() -> anyhow::Result<Self> {
        let (state_dir, cache_dir, torrent_state) = match std::env::var_os("TORTUGA_DATA_DIR") {
            Some(d) => {
                let d = PathBuf::from(d);
                (d.join("state"), d.join("cache"), d.join("torrents"))
            }
            None => {
                let dirs = directories::ProjectDirs::from("org", "Tortuga", "tortuga-helper")
                    .ok_or_else(|| anyhow::anyhow!("no home directory"))?;
                (dirs.data_dir().join("arti-state"), dirs.cache_dir().join("arti-cache"), dirs.data_dir().join("torrents"))
            }
        };
        let downloads = match std::env::var_os("TORTUGA_DOWNLOADS") {
            Some(d) => PathBuf::from(d),
            None => directories::UserDirs::new()
                .and_then(|u| u.download_dir().map(|d| d.to_path_buf()))
                .ok_or_else(|| anyhow::anyhow!("no Downloads folder"))?
                .join("Tortuga"),
        };
        let pt_dir = match std::env::var_os("TORTUGA_PT_DIR") {
            Some(d) => PathBuf::from(d),
            None => std::env::current_exe()?
                .parent()
                .ok_or_else(|| anyhow::anyhow!("executable has no directory"))?
                .join("pt"),
        };
        let exe = if cfg!(windows) { "lyrebird.exe" } else { "lyrebird" };
        Ok(Self {
            state_dir,
            cache_dir,
            lyrebird: pt_dir.join(exe),
            pt_config: pt_dir.join("pt_config.json"),
            downloads,
            torrent_state,
        })
    }
}

/// The default Snowflake bridge lines from the Expert Bundle's `pt_config.json`.
pub fn default_snowflake_lines(pt_config_json: &str) -> anyhow::Result<Vec<String>> {
    let v: serde_json::Value = serde_json::from_str(pt_config_json)?;
    let lines = v["bridges"]["snowflake"]
        .as_array()
        .ok_or_else(|| anyhow::anyhow!("pt_config.json has no snowflake bridges"))?
        .iter()
        .filter_map(|l| l.as_str())
        .map(|l| format!("Bridge {l}"))
        .collect::<Vec<_>>();
    anyhow::ensure!(!lines.is_empty(), "pt_config.json has no snowflake bridges");
    Ok(lines)
}

/// The Arti config for `choice`: own directories, and for bridge kinds only
/// those bridges, through `lyrebird`.
pub fn tor_config(choice: &BridgeChoice, paths: &Paths, default_snowflake: &[String]) -> anyhow::Result<TorClientConfig> {
    let mut builder = TorClientConfigBuilder::from_directories(&paths.state_dir, &paths.cache_dir);
    let (protocol, lines): (&str, Vec<String>) = match choice.kind {
        BridgeKind::None => return Ok(builder.build()?),
        BridgeKind::Snowflake if choice.lines.is_empty() => ("snowflake", default_snowflake.to_vec()),
        BridgeKind::Snowflake => ("snowflake", choice.lines.clone()),
        BridgeKind::Obfs4 => ("obfs4", choice.lines.clone()),
        BridgeKind::Webtunnel => ("webtunnel", choice.lines.clone()),
    };
    anyhow::ensure!(!lines.is_empty(), "{protocol} needs at least one bridge line");
    for line in &lines {
        let bridge: BridgeConfigBuilder = line.parse()?;
        builder.bridges().bridges().push(bridge);
    }
    let mut transport = TransportConfigBuilder::default();
    transport
        .protocols(vec![protocol.parse()?])
        .path(CfgPath::new_literal(&paths.lyrebird))
        .run_on_startup(true);
    builder.bridges().transports().push(transport);
    Ok(builder.build()?)
}

//! Messages between the extension and the helper (spec: "Protocol").
//! Every message is `{ id?, type, payload? }`; replies carry the request's id.

use serde::{Deserialize, Serialize};

use crate::hops::Hop;
use crate::torrents::{Progress, Source, TorrentInfo};

/// Bumped whenever a message changes incompatibly.
pub const PROTOCOL_VERSION: u32 = 1;

#[derive(Debug, Deserialize, PartialEq)]
pub struct Request {
    pub id: u64,
    #[serde(flatten)]
    pub body: RequestBody,
}

#[derive(Debug, Deserialize, PartialEq)]

    #[serde(rename = "torrent.add")]

    #[serde(rename = "torrent.pause")]
    TorrentPause { id: String },
    #[serde(rename = "torrent.resume")]

    #[serde(rename = "torrent.remove", rename_all = "camelCase")]

/// A torrent as the extension names it: `{ url }` (magnet or http(s) link to a
/// `.torrent`) or `{ torrentFile }` (the file, base64).
#[derive(Debug, Clone, Deserialize, PartialEq)]
#[serde(untagged, rename_all = "camelCase")]
pub enum SourceMsg {
    Url { url: String },
    #[serde(rename_all = "camelCase")]
    File { torrent_file: String },
}

impl SourceMsg {
    pub fn decode(&self) -> anyhow::Result<Source> {
        use base64::Engine as _;
        match self {
            SourceMsg::Url { url } if url.starts_with("magnet:") || url.starts_with("http://") || url.starts_with("https://") => {
                Ok(Source::Url(url.clone()))
            }
            SourceMsg::Url { url } => anyhow::bail!("not a magnet or http(s) link: {url}"),
            SourceMsg::File { torrent_file } => Ok(Source::File(base64::engine::general_purpose::STANDARD.decode(torrent_file)?)),
        }
    }
}

    Webtunnel,

#[derive(Debug, Serialize, PartialEq)]
#[serde(tag = "type", content = "payload")]
pub enum Outgoing {
    #[serde(rename = "hello")]
    Hello { protocol: u32, version: String },
    #[serde(rename = "ok")]
    Ok,
    #[serde(rename = "tor.status")]
    TorStatus { phase: Phase, percent: u8, blocked: Option<String> },
    #[serde(rename = "tor.ready", rename_all = "camelCase")]
    TorReady { socks_port: u16 },
    #[serde(rename = "circuit")]
    Circuit { site: String, bridge: Option<BridgeKind>, hops: Vec<Hop> },
    #[serde(rename = "torrent.info")]
    TorrentInfo(TorrentInfo),
    #[serde(rename = "torrent.progress")]

    #[serde(rename = "error")]

}

#[derive(Debug, Clone, Copy, Serialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum ErrorCode {
    BadRequest,
    HelloRequired,
    ProtocolMismatch,
    TorFailed,
    NotRunning,
    TorrentFailed,
}

impl Message {
    pub fn reply(id: u64, body: Outgoing) -> Self {
        Self { id: Some(id), body }
    }

    pub fn event(body: Outgoing) -> Self {
        Self { id: None, body }
    }

    pub fn error(id: Option<u64>, code: ErrorCode, message: impl ToString) -> Self {
        Self { id, body: Outgoing::Error { code, message: message.to_string() } }
    }

//! Handles requests from the extension: hello, then Tor (start, stop, new
//! circuit) and torrents. Long work runs in tasks, so a `tor.stop` can cancel
//! a start and a slow magnet lookup doesn't hold up other requests.
//!
//! The extension uses one helper process for Tor and another for torrents
//! (two native ports), so each part is opened only when first asked for.

use std::sync::Arc;
use std::time::Duration;

use tokio::net::TcpListener;
use tokio::sync::{Mutex, OnceCell};
use tokio::task::JoinHandle;

use crate::config::{Paths, default_snowflake_lines, tor_config};
use crate::protocol::{BridgeChoice, ErrorCode, Message, Outgoing, PROTOCOL_VERSION, Request, RequestBody, SourceMsg};
use crate::tor::{Events, Tor};
use crate::torrents::Torrents;

/// How often the Downloads tab gets fresh numbers.
const PROGRESS_EVERY: Duration = Duration::from_secs(1);

/// A torrent request, run in its own task.
enum TorrentJob {
    Inspect(SourceMsg),
    Add(SourceMsg),
    Pause(String),
    Resume(String),
    Remove(String, bool),
}

#[derive(Default)]
struct State {
    hello: bool,
    tor: Option<Arc<Tor>>,
    /// The bootstrap in progress, if any.
    starting: Option<JoinHandle<()>>,
    /// The SOCKS listener while Tor is on.
    socks: Option<JoinHandle<()>>,
}

#[derive(Clone)]
pub struct App {
    state: Arc<Mutex<State>>,
    paths: Paths,
    events: Events,
    torrents: Arc<OnceCell<Arc<Torrents>>>,
}

impl App {
    pub fn new(paths: Paths, events: Events) -> Self {
        Self { state: Arc::default(), paths, events, torrents: Arc::default() }
    }

    fn send(&self, m: Message) {
        let _ = self.events.send(m);
    }

    pub async fn handle(&self, req: Request) {
        let mut state = self.state.lock().await;
        if !state.hello && !matches!(req.body, RequestBody::Hello { .. }) {
            return self.send(Message::error(Some(req.id), ErrorCode::HelloRequired, "send hello first"));
        }
        match req.body {
            RequestBody::Hello { protocol } if protocol == PROTOCOL_VERSION => {
                state.hello = true;
                let version = env!("CARGO_PKG_VERSION").to_owned();
                self.send(Message::reply(req.id, Outgoing::Hello { protocol: PROTOCOL_VERSION, version }));
            }
            RequestBody::Hello { protocol } => self.send(Message::error(
                Some(req.id),
                ErrorCode::ProtocolMismatch,
                format!("helper speaks protocol {PROTOCOL_VERSION}, extension {protocol}"),
            )),
            RequestBody::TorStart { bridge } => {
                stop(&mut state);
                let app = self.clone();
                state.starting = Some(tokio::spawn(async move { app.start(req.id, bridge).await }));
            }
            RequestBody::TorStop => {
                stop(&mut state);
                self.send(Message::reply(req.id, Outgoing::Ok));
            }
            RequestBody::TorNewCircuit { site } => match &state.tor {
                Some(tor) if state.socks.is_some() => {
                    tor.new_circuit(&site);
                    self.send(Message::reply(req.id, Outgoing::Ok));
                }
                _ => self.send(Message::error(Some(req.id), ErrorCode::NotRunning, "Tor is off")),
            },
            RequestBody::TorrentInspect { source } => self.torrent(req.id, TorrentJob::Inspect(source)),
            RequestBody::TorrentAdd { source } => self.torrent(req.id, TorrentJob::Add(source)),
            RequestBody::TorrentPause { id } => self.torrent(req.id, TorrentJob::Pause(id)),
            RequestBody::TorrentResume { id } => self.torrent(req.id, TorrentJob::Resume(id)),
            RequestBody::TorrentRemove { id, delete_files } => self.torrent(req.id, TorrentJob::Remove(id, delete_files)),
        }
    }

    fn torrent(&self, id: u64, job: TorrentJob) {
        let app = self.clone();
        tokio::spawn(async move {
            let reply = match app.run_torrent(job).await {
                Ok(body) => Message::reply(id, body),
                Err(e) => Message::error(Some(id), ErrorCode::TorrentFailed, format!("{e:#}")),
            };
            app.send(reply);
        });
    }

    async fn run_torrent(&self, job: TorrentJob) -> anyhow::Result<Outgoing> {
        let torrents = self.open_torrents().await?;
        Ok(match job {
            TorrentJob::Inspect(source) => Outgoing::TorrentInfo(torrents.inspect(&source.decode()?).await?),
            TorrentJob::Add(source) => Outgoing::TorrentInfo(torrents.add(&source.decode()?).await?),
            TorrentJob::Pause(id) => torrents.pause(&id).await.map(|_| Outgoing::Ok)?,
            TorrentJob::Resume(id) => torrents.resume(&id).await.map(|_| Outgoing::Ok)?,
            TorrentJob::Remove(id, delete_files) => torrents.remove(&id, delete_files).await.map(|_| Outgoing::Ok)?,
        })
    }

    /// The torrent session, opened (and its saved downloads resumed) on first use.
    async fn open_torrents(&self) -> anyhow::Result<Arc<Torrents>> {
        let torrents = self
            .torrents
            .get_or_try_init(|| async {
                let t = Arc::new(Torrents::open(self.paths.downloads.clone(), self.paths.torrent_state.clone()).await?);
                tokio::spawn(report_progress(t.clone(), self.events.clone()));
                anyhow::Ok(t)
            })
            .await?;
        Ok(torrents.clone())
    }

    async fn start(&self, id: u64, bridge: BridgeChoice) {
        match self.try_start(&bridge).await {
            Ok(socks_port) => self.send(Message::reply(id, Outgoing::TorReady { socks_port })),
            Err(e) => self.send(Message::error(Some(id), ErrorCode::TorFailed, format!("{e:#}"))),
        }
    }

    async fn try_start(&self, bridge: &BridgeChoice) -> anyhow::Result<u16> {
        let defaults = match std::fs::read_to_string(&self.paths.pt_config) {
            Ok(json) => default_snowflake_lines(&json)?,
            Err(_) => Vec::new(),
        };
        let config = tor_config(bridge, &self.paths, &defaults)?;
        let existing = self.state.lock().await.tor.clone();
        let tor = match existing {
            Some(tor) => {
                tor.restart(&config, bridge.kind).await?;
                tor
            }
            None => Tor::start(config, bridge.kind, self.events.clone()).await?,
        };
        let listener = TcpListener::bind(("127.0.0.1", 0)).await?;
        let port = listener.local_addr()?.port();
        let socks = tokio::spawn(serve(listener, tor.clone()));
        let mut state = self.state.lock().await;
        state.tor = Some(tor);
        state.socks = Some(socks);
        state.starting = None;
        Ok(port)
    }
}

/// Cancel a start in progress, close the SOCKS port and let Tor sleep.
fn stop(state: &mut State) {
    if let Some(t) = state.starting.take() {
        t.abort();
    }
    if let Some(s) = state.socks.take() {
        s.abort();
    }
    if let Some(tor) = &state.tor {
        tor.sleep();
    }
}

/// Send the torrent list every second while there is something to show, and
/// once more when it becomes empty.
async fn report_progress(torrents: Arc<Torrents>, events: Events) {
    let mut last_empty = false;
    loop {
        let list = torrents.progress();
        let empty = list.is_empty();
        if !(empty && last_empty) && events.send(Message::event(Outgoing::TorrentProgress { torrents: list })).is_err() {
            return;
        }
        last_empty = empty;
        tokio::time::sleep(PROGRESS_EVERY).await;
    }
}

async fn serve(listener: TcpListener, tor: Arc<Tor>) {
    while let Ok((client, _)) = listener.accept().await {
        let tor = tor.clone();
        tokio::spawn(async move {
            if let Err(e) = crate::socks::handle(client, &tor).await {
                eprintln!("socks: {e}");
            }
        });
    }
}

//! tortuga-helper: the native messaging host the Tortuga extension starts.
//! stdin/stdout carry framed JSON messages; logs go to stderr only.

mod app;
mod config;
mod framing;
mod hops;
mod isolation;
mod protocol;
mod socks;
mod tor;
mod torrents;

use protocol::{ErrorCode, Message, Request};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let (events, mut outbox) = tokio::sync::mpsc::unbounded_channel::<Message>();

    let writer = tokio::spawn(async move {
        let mut stdout = tokio::io::stdout();
        while let Some(m) = outbox.recv().await {
            let bytes = serde_json::to_vec(&m)?;
            framing::write_message(&mut stdout, &bytes).await?;
        }
        anyhow::Ok(())
    });

    let app = app::App::new(config::Paths::discover()?, events.clone());
    let mut stdin = tokio::io::stdin();
    // The browser closes stdin when the extension disconnects: then we exit,
    // taking Tor with us.
    while let Some(bytes) = framing::read_message(&mut stdin).await? {
        match serde_json::from_slice::<Request>(&bytes) {
            Ok(req) => app.handle(req).await,
            Err(e) => {
                let _ = events.send(Message::error(None, ErrorCode::BadRequest, e));
            }
        }
    }
    drop(app);
    drop(events);
    let _ = tokio::time::timeout(std::time::Duration::from_secs(1), writer).await;
    Ok(())
}

#!/usr/bin/env python3
"""End-to-end check of the helper's torrents, acting as the browser.

Usage: torrent_check.py HELPER_BINARY MAGNET

Inspects the magnet (name, size), adds it, watches progress for 15 s, pauses,
resumes, then removes it with its files. Set TORTUGA_DOWNLOADS and
TORTUGA_DATA_DIR to throwaway folders. Exits non-zero on any failure.
"""
import json, os, queue, struct, subprocess, sys, threading, time

T0 = time.monotonic()

def log(*a):
    print(f"[{time.monotonic() - T0:6.1f}s]", *a, flush=True)

def send(p, msg):
    b = json.dumps(msg).encode()
    p.stdin.write(struct.pack("=I", len(b)) + b)
    p.stdin.flush()

def reader(p, q):
    while True:
        h = p.stdout.read(4)
        if len(h) < 4:
            q.put(None)
            return
        q.put(json.loads(p.stdout.read(struct.unpack("=I", h)[0])))

def reply(q, id, timeout):
    """The reply to request `id`; progress events on the way are kept in `rows`."""
    end = time.monotonic() + timeout
    while time.monotonic() < end:
        try:
            m = q.get(timeout=max(0.1, end - time.monotonic()))
        except queue.Empty:
            break
        if m is None:
            sys.exit("helper exited")
        if m.get("type") == "torrent.progress":
            rows[:] = m["payload"]["torrents"]
            continue
        if m.get("id") == id:
            return m
    sys.exit(f"no reply to {id}")

rows = []

def watch(q, seconds):
    end = time.monotonic() + seconds
    while time.monotonic() < end:
        try:
            m = q.get(timeout=0.5)
        except queue.Empty:
            continue
        if m and m.get("type") == "torrent.progress":
            rows[:] = m["payload"]["torrents"]
    return rows[0] if rows else None

def main():
    helper, magnet = sys.argv[1], sys.argv[2]
    p = subprocess.Popen([helper], stdin=subprocess.PIPE, stdout=subprocess.PIPE)
    q = queue.Queue()
    threading.Thread(target=reader, args=(p, q), daemon=True).start()
    send(p, {"id": 1, "type": "hello", "payload": {"protocol": 1}})
    reply(q, 1, 10)

    send(p, {"id": 2, "type": "torrent.inspect", "payload": {"source": {"url": magnet}}})
    info = reply(q, 2, 120)
    log("inspect:", json.dumps(info))
    if info["type"] != "torrent.info":
        sys.exit("inspect failed")
    tid = info["payload"]["id"]

    send(p, {"id": 3, "type": "torrent.add", "payload": {"source": {"url": magnet}}})
    added = reply(q, 3, 60)
    log("add:", json.dumps(added))
    if added["type"] != "torrent.info" or added["payload"]["files"] != info["payload"]["files"] or added["payload"]["size"] != info["payload"]["size"]:
        sys.exit("add reply differs from inspect")
    row = watch(q, 15)
    log("after 15 s:", json.dumps(row))
    if not row or row["id"] != tid or row["done"] <= 0 or row["state"] not in ("downloading", "seeding"):
        sys.exit("no download progress")

    send(p, {"id": 4, "type": "torrent.pause", "payload": {"id": tid}})
    log("pause:", reply(q, 4, 10)["type"])
    row = watch(q, 3)
    log("paused row:", row["state"], row["downRate"])
    if row["state"] != "paused":
        sys.exit("not paused")

    send(p, {"id": 5, "type": "torrent.resume", "payload": {"id": tid}})
    log("resume:", reply(q, 5, 10)["type"])
    row = watch(q, 3)
    log("resumed row:", row["state"])

    folder = info["payload"]["folder"]
    before = os.listdir(folder)
    send(p, {"id": 6, "type": "torrent.remove", "payload": {"id": tid, "deleteFiles": True}})
    log("remove:", reply(q, 6, 20)["type"])
    watch(q, 2)
    log("rows after remove:", len(rows), "| folder before:", before, "after:", os.listdir(folder))
    if rows or os.listdir(folder):
        sys.exit("files or rows left after remove")

    send(p, {"id": 7, "type": "torrent.add", "payload": {"source": {"url": "javascript:alert(1)"}}})
    bad = reply(q, 7, 10)
    log("bad link:", json.dumps(bad))
    if bad["type"] != "error" or bad["payload"]["code"] != "torrent_failed":
        sys.exit("bad link not refused")
    p.stdin.close()
    p.wait(timeout=10)
    log("PASS")

main()

import type { TorrentRow } from './protocol';

/**
 * A link the Downloads feature takes: a magnet with a BitTorrent info hash, or
 * an http(s) address whose path ends in `.torrent`.
 */
export function isTorrentLink(href: string): boolean {
  if (/^magnet:\?/i.test(href)) return /[?&]xt=urn:bt(ih|mh):/i.test(href);
  try {
    const u = new URL(href);
    return (u.protocol === 'http:' || u.protocol === 'https:') && /\.torrent$/i.test(u.pathname);
  } catch {
    return false;
  }
}

const UNITS = ['B', 'KB', 'MB', 'GB', 'TB'];

/** 1536 → "1.5 KB"; one decimal below 100, none above. */
export function formatBytes(n: number): string {
  let v = Math.max(0, n);
  let i = 0;
  while (v >= 1024 && i < UNITS.length - 1) {
    v /= 1024;
    i++;
  }
  const digits = i === 0 || v >= 100 ? 0 : 1;
  return `${v.toFixed(digits)} ${UNITS[i]}`;
}

export function percent(row: TorrentRow): number {
  return row.size > 0 ? Math.min(100, Math.floor((row.done / row.size) * 100)) : 0;
}

/** The line under a download's name. */
export function rowLine(row: TorrentRow): string {
  switch (row.state) {
    case 'starting':
      return 'Starting…';
    case 'downloading':
      return `${formatBytes(row.done)} of ${formatBytes(row.size)} · ${formatBytes(row.downRate)}/s`;
    case 'seeding':
      return `Done · ${formatBytes(row.size)} · sharing ${formatBytes(row.upRate)}/s`;
    case 'paused':
      return `Paused · ${percent(row)}% of ${formatBytes(row.size)}`;
    case 'error':
      return `Error: ${row.error ?? 'unknown'}`;
  }
}

/** Downloads still getting data, for the tab's badge. */
export function activeCount(rows: TorrentRow[]): number {
  return rows.filter(r => r.state === 'starting' || r.state === 'downloading').length;
}

import type { DownloadsState } from '../lib/messages';
import { PROTOCOL_VERSION, type HelperMessage, type TorrentInfo, type TorrentSource } from '../lib/protocol';
import { HELPER_MISSING } from './controller';
import { isMissingHost, type HelperClient } from './helper';

/** Everything the downloads controller does to the outside world (fakes in tests). */
export interface DlDeps {
  connect(onEvent: (m: HelperMessage) => void, onGone: (reason: string) => void): HelperClient;
  broadcast(state: DownloadsState): void;
  /** Remember whether there are downloads, so a restarted browser resumes them. */
  saveActive(active: boolean): Promise<void>;
}

export const NO_DOWNLOADS: DownloadsState = { rows: [], folder: null, error: null, helperMissing: false };

/**
 * Torrents run in their own helper process, on a native port of their own:
 * Tor can be on or off without touching downloads. The port is opened on the
 * first request and kept while the browser runs.
 */
export class Downloads {
  private state: DownloadsState = NO_DOWNLOADS;
  private ready: Promise<HelperClient> | null = null;
  private active = false;

  constructor(private readonly deps: DlDeps) {}

  get current(): DownloadsState {
    return this.state;
  }

  /** Connect now (on startup, when there were downloads to resume). */
  async resume(): Promise<void> {
    await this.client().catch(() => undefined);
  }

  async inspect(source: TorrentSource): Promise<TorrentInfo> {
    return this.info(await this.request({ type: 'torrent.inspect', payload: { source } }));
  }

  async add(source: TorrentSource): Promise<TorrentInfo> {
    const info = this.info(await this.request({ type: 'torrent.add', payload: { source } }));
    await this.setActive(true);
    return info;
  }

  async pause(id: string): Promise<void> {
    await this.request({ type: 'torrent.pause', payload: { id } });
  }

  async resumeOne(id: string): Promise<void> {
    await this.request({ type: 'torrent.resume', payload: { id } });
  }

  async remove(id: string, deleteFiles: boolean): Promise<void> {
    await this.request({ type: 'torrent.remove', payload: { id, deleteFiles } });
  }

  private info(m: HelperMessage): TorrentInfo {
    if (m.type !== 'torrent.info') throw new Error(`unexpected reply ${m.type}`);
    this.update({ folder: m.payload.folder });
    return m.payload;
  }

  private async request(req: Parameters<HelperClient['request']>[0]): Promise<HelperMessage> {
    const helper = await this.client();
    return helper.request(req);
  }

  private client(): Promise<HelperClient> {
    if (!this.ready) {
      const ready = (async () => {
        const helper = this.deps.connect(m => this.onEvent(m), reason => this.onGone(reason));
        await helper.request({ type: 'hello', payload: { protocol: PROTOCOL_VERSION } });
        this.update({ error: null, helperMissing: false });
        return helper;
      })();
      this.ready = ready;
      ready.catch(() => {
        if (this.ready === ready) this.ready = null;
      });
    }
    return this.ready;
  }

  private onEvent(m: HelperMessage): void {
    if (m.type !== 'torrent.progress') return;
    this.update({ rows: m.payload.torrents });
    void this.setActive(m.payload.torrents.length > 0);
  }

  private onGone(reason: string): void {
    this.ready = null;
    const missing = isMissingHost(reason);
    // The rows are stale once the helper is gone; they come back when it does.
    this.update({ rows: [], error: missing ? HELPER_MISSING : reason, helperMissing: missing });
  }

  private async setActive(active: boolean): Promise<void> {
    if (active === this.active) return;
    this.active = active;
    await this.deps.saveActive(active);
  }

  private update(change: Partial<DownloadsState>): void {
    this.state = { ...this.state, ...change };
    this.deps.broadcast(this.state);
  }
}

  $('error').textContent = error;
  $('error').hidden = false;

  cancel.textContent = 'Close';

  connect: connectHelper,

  applyRoute: port => (__TARGET__ === 'firefox' ? Promise.resolve() : applyChromeRoute(port)),

  chrome.runtime.sendMessage(msg).catch(() => { /* no popup open */ });
}

const downloads = new Downloads({
  connect: connectHelper,
  broadcast: state => broadcast({ type: 'DOWNLOADS', state }),
  saveActive: active => chrome.storage.local.set({ [DOWNLOADS_KEY]: active }),

void chrome.storage.local.get(DOWNLOADS_KEY).then(r => {

/** Torrents waiting in a confirm window, by the window's token. */
const pending = new Map<string, TorrentSource>();

/** Put a torrent up for confirmation in a small window of its own. */
async function openConfirm(source: TorrentSource): Promise<void> {
  const token = crypto.randomUUID();
  pending.set(token, source);
  await chrome.windows.create({ url: chrome.runtime.getURL(`confirm.html?t=${token}`), type: 'popup', width: 440, height: 420 });
}

async function result(run: () => Promise<TorrentInfo>): Promise<DlResult> {
  try {
    return { ok: true, info: await run() };
  } catch (e) {
    return { ok: false, error: (e as Error).message };
  }
}

function sourceOf(token: string): TorrentSource {
  const source = pending.get(token);
  if (!source) throw new Error('This link has expired. Click it again.');
  return source;
}

const MENU_ID = 'tortuga-download';
chrome.runtime.onInstalled.addListener(() => {
  chrome.contextMenus.create({ id: MENU_ID, title: 'Download with Tortuga', contexts: ['link'] });
});
chrome.contextMenus.onClicked.addListener(info => {
  if (info.menuItemId === MENU_ID && info.linkUrl) void openConfirm({ url: info.linkUrl });
});

/** Bridge lines saved on the settings page for `kind`. */
async function savedLines(kind: BridgeKind): Promise<string[]> {
  const r = await chrome.storage.local.get(LINES_KEY);
  return linesFor(kind, (r[LINES_KEY] as BridgeLines | undefined) ?? NO_LINES);
}

// Back to how it was when the background last stopped. If Tortuga was on, it
// starts again; until Tor is ready, routedPort() blocks traffic instead of
// letting it out directly.
const restored = chrome.storage.local.get(STORAGE_KEY).then(async r => {
  const stored = r[STORAGE_KEY] as Stored | undefined;
  if (stored?.enabled) await controller.turnOn(stored.bridge, await savedLines(stored.bridge));
  else if (stored) await controller.chooseBridge(stored.bridge);
});

if (__TARGET__ === 'firefox') {
  // A persistent listener: Firefox wakes the background for it. Requests wait
  // for the stored state, so none slips out before Tortuga knows it is on.
  chrome.proxy.onRequest.addListener(async details => {
    await restored;
    return firefoxAnswer(controller.port, details);
  }, { urls: ['<all_urls>'] });
}

chrome.runtime.onMessage.addListener((msg: BgMessage | DlMessage, _sender, sendResponse) => {
  const reply = (p: Promise<TorState>) => {
    p.then(sendResponse, () => sendResponse(controller.current));
    return true;
  };
  const answer = (p: Promise<unknown>) => {
    p.then(sendResponse, e => sendResponse({ ok: false, error: (e as Error).message }));
    return true;
  };
  switch (msg.type) {
    case 'GET_STATE':
      return reply(restored.then(() => controller.current));
    case 'TOR_ON':
      return reply(savedLines(msg.bridge).then(lines => controller.turnOn(msg.bridge, lines)));
    case 'TOR_OFF':
      return reply(controller.turnOff());
    case 'SET_BRIDGE':
      return reply(savedLines(msg.bridge).then(lines => controller.chooseBridge(msg.bridge, lines)));
    case 'NEW_CIRCUIT':
      return reply(controller.newCircuit(msg.site));
    case 'GET_DOWNLOADS':
      return answer(Promise.resolve(downloads.current));
    case 'TORRENT_OPEN':
      // Pages only ever ask for links that look like torrents; refuse anything else.
      if ('url' in msg.source && !isTorrentLink(msg.source.url)) return answer(Promise.resolve({ ok: false, error: 'Not a magnet or .torrent link' }));
      return answer(openConfirm(msg.source).then(() => ({ ok: true })));
    case 'TORRENT_INSPECT':
      return answer(result(() => downloads.inspect(sourceOf(msg.token))));
    case 'TORRENT_CONFIRM':
      return answer(result(async () => {
        const info = await downloads.add(sourceOf(msg.token));
        pending.delete(msg.token);
        return info;
      }));
    case 'TORRENT_CANCEL':
      pending.delete(msg.token);
      return answer(Promise.resolve({ ok: true }));
    case 'TORRENT_PAUSE':
      return answer(downloads.pause(msg.id).then(() => downloads.current));
    case 'TORRENT_RESUME':
      return answer(downloads.resumeOne(msg.id).then(() => downloads.current));
    case 'TORRENT_REMOVE':
      return answer(downloads.remove(msg.id, msg.deleteFiles).then(() => downloads.current));
  }
  return false;
});

// The Downloads tab: add a torrent (link or file), and one row per download
// with progress, pause / resume and remove (keeping or deleting the files).
import { activeCount, isTorrentLink, percent, rowLine } from '../lib/downloads';
import type { DlMessage, DownloadsState } from '../lib/messages';
import type { TorrentRow } from '../lib/protocol';

const $ = <T extends HTMLElement>(id: string) => document.getElementById(id) as T;
const rows = $<HTMLUListElement>('rows');
const empty = $('empty');
const error = $('dlError');
const folder = $('folder');
const badge = $('badge');
const addForm = $<HTMLFormElement>('addForm');
const addInput = $<HTMLInputElement>('addInput');
const addFile = $<HTMLInputElement>('addFile');

/** The row whose Remove asked "keep or delete files?", if any. */
let removing: string | null = null;
let last: DownloadsState | null = null;

function send(msg: DlMessage): Promise<unknown> {
  return chrome.runtime.sendMessage(msg);
}

function showError(text: string | null): void {
  error.textContent = text ?? '';
  error.hidden = !text;
}

function button(label: string, title: string, onClick: () => void, cls = 'icon'): HTMLButtonElement {
  const b = Object.assign(document.createElement('button'), { type: 'button', className: `btn ${cls}`, textContent: label, title });
  b.setAttribute('aria-label', title);
  b.addEventListener('click', onClick);
  return b;
}

function rowNode(r: TorrentRow): HTMLLIElement {
  const li = document.createElement('li');
  li.className = `row row-${r.state}`;
  const head = document.createElement('div');
  head.className = 'row-head';
  const name = Object.assign(document.createElement('span'), { className: 'row-name', textContent: r.name, title: r.name });
  const actions = document.createElement('span');
  actions.className = 'row-actions';
  if (r.state === 'paused') actions.append(button('▶', 'Resume', () => void send({ type: 'TORRENT_RESUME', id: r.id })));
  else if (r.state !== 'error') actions.append(button('⏸', 'Pause', () => void send({ type: 'TORRENT_PAUSE', id: r.id })));
  actions.append(button('✕', 'Remove', () => { removing = r.id; redraw(); }));
  head.append(name, actions);

  const bar = document.createElement('div');
  bar.className = 'progress';
  const fill = document.createElement('i');
  fill.style.width = `${percent(r)}%`;
  bar.append(fill);

  const line = Object.assign(document.createElement('div'), { className: 'row-line', textContent: rowLine(r) });
  li.append(head, bar, line);

  if (removing === r.id) {
    const ask = document.createElement('div');
    ask.className = 'row-remove';
    ask.append(
      Object.assign(document.createElement('span'), { textContent: 'Remove and stop sharing?' }),
      button('Keep files', 'Remove, keep the files', () => remove(r.id, false), 'small'),
      button('Delete files', 'Remove and delete the files', () => remove(r.id, true), 'small danger'),
      button('Cancel', 'Cancel', () => { removing = null; redraw(); }, 'small'),
    );
    li.append(ask);
  }
  return li;
}

function remove(id: string, deleteFiles: boolean): void {
  removing = null;
  void send({ type: 'TORRENT_REMOVE', id, deleteFiles });
}

  if (!last) return;
  rows.replaceChildren(...last.rows.map(rowNode));

import { parseLines, type LineKind } from '../lib/bridges';
import { LINES_KEY, NO_LINES, type BgMessage, type BridgeLines, type DlMessage, type DownloadsState } from '../lib/messages';
import type { TorState } from '../lib/state';
import { chooseTheme, chosenTheme, clearTheme } from '../lib/theme';
import { helperText } from './helper-text';

const $ = <T extends HTMLElement>(id: string) => document.getElementById(id) as T;
const KINDS: LineKind[] = ['obfs4', 'webtunnel'];

async function showHelper(): Promise<void> {
  const s: TorState = await chrome.runtime.sendMessage({ type: 'GET_STATE' } satisfies BgMessage);
  $('helper').textContent = helperText(s);
}

async function showDownloads(): Promise<void> {
  const d: DownloadsState = await chrome.runtime.sendMessage({ type: 'GET_DOWNLOADS' } satisfies DlMessage);
  if (d.folder) $('downloads').textContent = `Torrents are saved in ${d.folder}.`;
}

async function loadLines(): Promise<void> {
  const saved = ((await chrome.storage.local.get(LINES_KEY))[LINES_KEY] as BridgeLines | undefined) ?? NO_LINES;
  for (const kind of KINDS) $<HTMLTextAreaElement>(kind).value = saved[kind].map(l => l.replace(/^Bridge /, '')).join('\n');
}

async function saveLines(): Promise<void> {
  const next: BridgeLines = { obfs4: [], webtunnel: [] };
  let bad = false;
  for (const kind of KINDS) {
    const { lines, errors } = parseLines(kind, $<HTMLTextAreaElement>(kind).value);
    const list = $(`${kind}Errors`);
    list.replaceChildren(...errors.map(text => Object.assign(document.createElement('li'), { textContent: text })));
    list.hidden = errors.length === 0;
    bad ||= errors.length > 0;
    next[kind] = lines;
  }
  if (bad) {
    $('saved').textContent = 'Fix the lines marked above.';
    return;
  }
  await chrome.storage.local.set({ [LINES_KEY]: next });
  $('saved').textContent = `Saved: ${next.obfs4.length} obfs4, ${next.webtunnel.length} WebTunnel.`;
}

function initTheme(): void {
  const current = chosenTheme() ?? 'system';
  document.querySelectorAll<HTMLInputElement>('input[name="theme"]').forEach(input => {
    input.checked = input.value === current;
    input.addEventListener('change', () => {
      if (input.value === 'system') clearTheme();
      else chooseTheme(input.value as 'light' | 'dark');
    });
  });
}

$('save').addEventListener('click', () => void saveLines());
initTheme();
void loadLines();
void showHelper();
void showDownloads();

// (BiDi :9222) with site/links.html served on 127.0.0.1:8765: a click on a

const sleep = ms => new Promise(r => setTimeout(r, ms));
let failures = 0;
const check = (ok, what) => { log(ok ? 'PASS' : 'FAIL', what); if (!ok) failures++; };

const ws = new WebSocket('ws://127.0.0.1:9222/session');
await new Promise((res, rej) => { ws.onopen = res; ws.onerror = rej; });
let nextId = 1;
const waiting = new Map();
ws.onmessage = e => { const m = JSON.parse(e.data); if (m.id && waiting.has(m.id)) { waiting.get(m.id)(m); waiting.delete(m.id); } };
const cmd = (method, params = {}) => new Promise((res, rej) => {
  const id = nextId++;
  waiting.set(id, m => (m.type === 'error' ? rej(new Error(`${method}: ${m.message}`)) : res(m.result)));
  ws.send(JSON.stringify({ id, method, params }));
});
const ev = async (context, expression) => {
  const r = await cmd('script.evaluate', { expression, target: { context }, awaitPromise: true });
  if (r.type === 'exception') throw new Error(r.exceptionDetails.text);
  return r.result.value;
};
const contexts = async () => (await cmd('browsingContext.getTree', {})).contexts;
async function waitFor(pred, ms, what) {
  for (let i = 0; i < ms / 250; i++) { const v = await pred(); if (v) return v; await sleep(250); }
  throw new Error(`timed out: ${what}`);
}
async function shot(context, name) {
  const width = Math.ceil(await ev(context, 'document.body.getBoundingClientRect().width'));
  const height = Math.ceil(await ev(context, 'document.documentElement.scrollHeight'));
  const { data } = await cmd('browsingContext.captureScreenshot', { context, clip: { type: 'box', x: 0, y: 0, width, height } });
  writeFileSync(`${SHOTS}/${name}.png`, Buffer.from(data, 'base64'));
}

await cmd('session.new', { capabilities: {} });
const win = (await cmd('browsingContext.getTree', { 'moz:scope': 'chrome' })).contexts[0].context;
const host = await ev(win, `WebExtensionPolicy.getByID('tortuga@legenki.com').mozExtensionHostname`);

// 1. A page with torrent links.
const { context: page } = await cmd('browsingContext.create', { type: 'tab' });
await cmd('browsingContext.navigate', { context: page, url: 'http://127.0.0.1:8765/links.html', wait: 'complete' });
await sleep(500);
const known = new Set((await contexts()).map(c => c.context));
await ev(page, `document.getElementById('magnet').click(); 1`);
const confirmCtx = await waitFor(async () => (await contexts()).find(c => !known.has(c.context) && c.url.includes('confirm.html'))?.context, 10000, 'confirm window');
check(true, 'magnet click opened the confirm window');
check((await ev(page, 'location.href')) === 'http://127.0.0.1:8765/links.html', 'the page did not follow the magnet link');

// 2. Confirm window: details, then Download.
await waitFor(() => ev(confirmCtx, `!document.getElementById('details').hidden`), 60000, 'torrent details');
const name = await ev(confirmCtx, `document.getElementById('name').textContent`);
const size = await ev(confirmCtx, `document.getElementById('size').textContent`);
log('confirm shows:', name, size, await ev(confirmCtx, `document.getElementById('folder').textContent`));
check(name === 'debian-13.7.0-amd64-netinst.iso' && size === '756 MB', 'name and size before downloading');
await shot(confirmCtx, 'confirm');
await ev(confirmCtx, `document.getElementById('download').click(); 1`);
await waitFor(async () => !(await contexts()).some(c => c.context === confirmCtx), 10000, 'confirm window closes').catch(e => check(false, e.message));
check(true, 'confirm window closed after Download');

// 3. Popup → Downloads tab.
const before = new Set((await contexts()).map(c => c.context));
await ev(win, `(gBrowser.selectedTab = gBrowser.addTrustedTab('moz-extension://${host}/popup.html'), 1)`);
const popup = await waitFor(async () => (await contexts()).find(c => !before.has(c.context) && c.url.includes('popup.html'))?.context, 10000, 'popup');
await sleep(800);
await ev(popup, `document.getElementById('tabDownloads').click(); 1`);
const row = await waitFor(async () => {
  const d = await ev(popup, `chrome.runtime.sendMessage({ type: 'GET_DOWNLOADS' }).then(d => JSON.stringify(d))`).then(JSON.parse);
  const r = d.rows[0];
  return r && r.state === 'downloading' && r.done > 20e6 ? r : null;
}, 60000, 'download progress');
log('row:', JSON.stringify(row));
check(row.name === name, 'the download shows in the Downloads tab');
await sleep(1200);
log('popup says:', await ev(popup, `document.querySelector('.row-line')?.textContent`), '| badge', await ev(popup, `document.getElementById('badge').textContent`));
await shot(popup, 'downloads');

// 4. Pause, resume.
await ev(popup, `document.querySelector('.row-actions button[title="Pause"]').click(); 1`);
await waitFor(() => ev(popup, `!!document.querySelector('.row-paused')`), 10000, 'paused row');
check(true, 'Pause works');
await ev(popup, `document.querySelector('.row-actions button[title="Resume"]').click(); 1`);
await waitFor(() => ev(popup, `!!document.querySelector('.row-downloading, .row-starting')`), 10000, 'resumed row');
check(true, 'Resume works');

// 5. Remove with files.
await ev(popup, `document.querySelector('.row-actions button[title="Remove"]').click(); 1`);
await sleep(300);
await shot(popup, 'remove-ask');
await ev(popup, `document.querySelector('.row-remove button[title="Remove and delete the files"]').click(); 1`);
await waitFor(() => ev(popup, `document.querySelectorAll('#rows > li').length === 0`), 10000, 'row gone');

check(readdirSync(DL_DIR).length === 0, `files deleted (left: ${readdirSync(DL_DIR).join(', ') || 'none'})`);

// 6. A .torrent link, then Cancel.
const known2 = new Set((await contexts()).map(c => c.context));
await cmd('browsingContext.activate', { context: page });

const confirm2 = await waitFor(async () => (await contexts()).find(c => !known2.has(c.context) && c.url.includes('confirm.html'))?.context, 10000, 'second confirm window');

check(true, '.torrent link opens the confirm window with details');

await waitFor(async () => !(await contexts()).some(c => c.context === confirm2), 10000, 'cancel closes');
await sleep(1500);
const after = await ev(popup, `chrome.runtime.sendMessage({ type: 'GET_DOWNLOADS' }).then(d => d.rows.length)`);
check(after === 0, 'Cancel downloads nothing');

// 7. A plain link is left alone.
await ev(page, `document.getElementById('plain').addEventListener('click', e => e.preventDefault()); document.getElementById('plain').click(); 1`);
await sleep(800);
check(!(await contexts()).some(c => c.url.includes('confirm.html')), 'a normal link opens no confirm window');

log(failures ? `${failures} FAILED` : 'ALL PASSED');
await Promise.race([cmd('session.end', {}).catch(() => {}), sleep(1000)]);
process.exit(failures ? 1 : 0);

- [ ] **Step 3: Spec**

In `docs/superpowers/specs/2026-11-05-tortuga-design.md`:
1. *Helper → Torrents*: the session opens on the first torrent request; the extension uses a second native port (a second helper process) for torrents, so they run with Tor on or off; ids are info hashes; `.torrent` URLs are fetched by the helper without browser cookies (no private trackers in v1); the folder is fixed at `~/Downloads/Tortuga` in v1 and shown on the settings page (drop "changeable on the settings page").
2. *Protocol*: replace the torrent rows with `torrent.inspect` / `torrent.add { source: { url } | { torrentFile } }` → `torrent.info { id, name, size, files, folder }`; `torrent.pause / resume { id }`, `torrent.remove { id, deleteFiles }` → `ok`; event `torrent.progress { torrents: [{ id, name, done, size, downRate, upRate, state, error }] }` every second; error code `torrent_failed`.
3. *Starting a download*: the confirm window is opened by the background with a one-time token for the pending torrent; it inspects first (a magnet needs peers: after 8 s it says so) and adds only on **Download**.
4. *Errors*: cold Snowflake starts took 11 s, 22 s and about 100 s in planning runs.
