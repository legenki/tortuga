Bridge lines

obfs4 and WebTunnel need bridge addresses. Get … lines asks bridges.torproject.org: for a network where Tor is blocked it hands out bridges, elsewhere the public built-in ones. If the site itself is blocked, turn Tor on with Snowflake first — the request then goes through Tor. You can also paste lines from bridges.torproject.org or the Tor Project’s Telegram bot, one per line. Snowflake needs none.
